# Mapa do Poder

Árvore interativa que mostra quantos políticos, ministros e assessores o poder público brasileiro sustenta, e quanto isso custa.

## Abrir

Abra `index.html` no navegador. Não precisa de instalação nem de build.

## Publicar

Publicado em https://wkliemann.github.io/mapa-do-poder-brasil/ via GitHub Pages (branch `main`, raiz).

## Atualizar os números

Todos os dados ficam em `js/data.js`: valores de referência (`REF`), bancadas por estado (`ESTADOS`) e fontes (`FONTES`).

Ao publicar mudanças em CSS/JS, aumente o `?v=` nas tags do `index.html` para o navegador não usar a versão antiga em cache.
